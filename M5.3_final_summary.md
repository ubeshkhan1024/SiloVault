### Key Design Decisions

1. **Dependency-free testing**: Tests use module-level mocks for torch/transformers/PIL — no package installations or model downloads required.

2. **Fake loaded model injection**: Tests inject `{"processor": mock_processor, "model": mock_model}` directly into `runtime._loaded_model`, bypassing the `initialize()`/`load_model()` paths.

3. **Fail-closed behavior**: The runtime preserves all existing error handling — `RuntimeNotReadyError`, `ExecutionError`, `CancellationError` all work correctly.

4. **No network access**: `local_files_only=True` ensures no Hugging Face Hub contact after model installation.

5. **CPU-safe dtype**: `torch.float32` used for CPU inference — float16 would cause precision issues on CPU.
